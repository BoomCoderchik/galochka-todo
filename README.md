# Галочка

Личный список задач в виде бумажного блокнота. Добавляйте задачи, отмечайте выполненные, фильтруйте и удаляйте их. Прогресс пересчитывается автоматически.

## Запуск

Откройте опубликованную [версию на GitHub Pages](https://boomcoderchik.github.io/galochka-todo/).

Для локальной работы запустите любой статический сервер из корня репозитория. Например, при установленном Python:

```sh
python -m http.server 8000
```

Откройте [localhost:8000](http://localhost:8000). Проект использует HTML, CSS и JavaScript без зависимостей и сборки. Задачи сохраняются в localStorage текущего браузера. У каждого браузера и адреса сайта свой список.

## Быстрая проверка

1. Добавьте две задачи, одну через Enter, другую кнопкой.
2. Отметьте одну выполненной. Проверьте зачёркивание, прогресс и оба фильтра.
3. Обновите страницу. Убедитесь, что задачи и отметка сохранились.
4. Удалите обе задачи, снова обновите страницу и проверьте пустое состояние.

## Использование ИИ

OpenAI Codex помог спроектировать интерфейс, написать код и проверить пользовательские сценарии в браузере. OpenAI ImageGen использовался для визуального референса. Интерфейс реализован средствами HTML и CSS.
